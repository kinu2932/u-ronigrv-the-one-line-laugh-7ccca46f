One funny line, at most 200 characters, written by `main.py` (Python 3.13, stdlib only) to `/output/entry.txt`.

## The line

> I set four alarms every night, and every morning all five of us hit snooze.

## Run

```sh
python3 main.py
```

Writes `entry.txt` (no trailing newline) to `$MAKEFUN_OUTPUT_DIR` or `/output`, and prints the line.
